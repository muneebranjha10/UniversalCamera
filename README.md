# UniversalCamera | @s23_hype

Experimental Samsung Camera enhancement. Target: Samsung-only LSPosed companion plus optional KernelSU/Magisk installer. This is not a verified universal release. No stock Camera APK or proprietary assets are distributed. Hardware-gated recording menu changes may not work on every firmware. Do not force unsupported resolutions or FPS. Use LSPosed scope Samsung Camera only; disable the companion if Camera fails. Build and physical-device testing are separate milestones.
